# AGENT — Правила для ИИ-ассистента

- Всегда работай маленькими шагами: одна задача — одно изменение.
- Каждая новая функция должна сопровождаться юнит-тестами (если это возможно).
- Тесты должны проходить перед каждым коммитом (`go test ./...`).
- API-токен никогда не должен попадать в код или в репозиторий. Токен читается только из файла `.env` (в коде использовать переменные окружения).
- Не забывай обновлять README.md при изменении способа запуска или конфигурации.
- Соблюдай структуру проекта, описанную в SPEC.md.
- При возникновении ошибок — выводи их понятным текстом в интерфейсе, а не аварийно завершай программу.
