помоги создать консольный дашборд по расчету процента волатильности указанных акци, монет и т.д. Работаем через Finam Trade API (gRPC) и официальный GO SDK (github.com/FinamWeb/finam-trade-api). Интерфейс - Go + tview. Документация по API - https:/api/finam/ru/docs-new/gprc-new/
Что должна делать программа:
Рассчитывает % волатильности как по заданному списку инструментов, так и по одному введенному в интерфейсе
введенный новый инструмент добавляет в список или акций, или монет, или облигаций
Данные берет из Trade API
все запросы и результаты записывает в БД для истории
как должен выглядеть интерфейс - один экран, три зоны
Слева на право заданный список, по монетам, по акциям, по облигациям с рассчитанным % волатильности
каждый список в виде таблицы с колонками
тикер
% волатильности
торг
колонка Торг заполняется по следующему правилу - если % волатильности меньше 1-цы красным шрифтом = не торгуем; если % волатильности больше единицы но меньше 1.5 - оранжевым цветом - можно попытаться; и если более 1.5 до 3, то пишем зеленым цветом - торгуем точно; если свышке 3 - то фиолетовым цветом - торгуем осторожно
снизу строка поиска по заданному названию или тикеру с последующим запросом после поиска - добавить или не добавить тикер в список
