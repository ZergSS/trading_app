# SPEC — Консольный дашборд волатильности инструментов

## Назначение
Программа отображает в терминале (TUI) процент волатильности для трёх групп инструментов:
- **Акции** (Finam Trade API, gRPC)
- **Облигации** (Finam Trade API, gRPC)
- **Монеты** (фьючерсы на криптовалюту, например BTCUSDT; данные Bybit API)

Дополнительно есть таблица «Прочее» для инструментов, не попавших в основные категории.

## Формула расчёта
Для каждого инструмента берутся 5 последних дневных свечей (High, Low, Close).
Процент волатильности вычисляется как:

$$
\text{Процент волатильности} = \frac{\sum_{i=1}^{5} (High_i - Low_i)}{5 \times Close_{\text{last}}} \times 100\%,  $$
где:
- High и Low - самая высокая и самая низкая цена сессии (дня) по 5-ти дням
- $Close_{last}$ - цена закрытия последней сессии (5-го дня)
> 	если `Процент волатильности` меньше 1-цы - НЕ ТОРГУЕМ ИНСТРУМЕНТ!

## Источники данных
### Finam (акции и облигации)
- Библиотека: `github.com/FinamWeb/finam-trade-api`
- Доступ: gRPC, требует API-токен (в `.env`)
- Типы инструментов:
    - Акции — `STOCK`
    - Облигации — `BOND`
    - Прочее — ETF, FORTS и др.

### Bybit (монеты)
- Библиотека: `github.com/bybit-exchange/bybit.go.api`
- Доступ: публичный REST API (без токена)
- Категория: `linear` (линейные фьючерсы), символы вида `BTCUSDT`

## Пользовательский интерфейс
- Один экран на базе `tview`.
- Три основные таблицы (слева направо): Монеты, Акции, Облигации. Плюс таблица «Прочее».
- Колонки таблиц: `Тикер | % волатильности | Торг`
- Цветовая индикация колонки «Торг»:
    - `< 1.0` — красный, «не торгуем»
    - `1.0 – 1.5` — оранжевый, «можно попытаться»
    - `1.5 – 3.0` — зелёный, «торгуем точно»
    - `> 3.0` — фиолетовый, «торгуем осторожно»
- Внизу — строка поиска. Ввод названия или тикера вызывает поиск по Finam (для акций/облигаций) или по Bybit (для монет). Результаты показываются в модальном окне, пользователь выбирает нужный инструмент, и он добавляется в соответствующую таблицу (или в «Прочее», если тип не подходит).

## Обновление данных
- Вручную — клавиша `F5`.
- Автоматически — с интервалом, заданным в `.env` (по умолчанию 60 секунд).

## База данных (SQLite)
- Таблица `instruments` — найденные инструменты (id, ticker, name, type).
- Таблица `volatility_history` — история расчётов (id, ticker, date, volatility, price).
- Файл БД указывается в `.env` (`DB_PATH`).

## Обработка ошибок
- При недоступности API, неверном токене или других сетевых ошибках программа показывает сообщение об ошибке в отдельном окне и продолжает работать.
- Критические ошибки (например, невозможность создать БД) приводят к завершению с понятным текстом в консоли.

## Конфигурация (`.env`)
FINAM_TOKEN=ваш_токен 

DB_PATH=dashboard.db 

UPDATE_INTERVAL=60 

VOLATILITY_PERIOD=5 # число свечей (по умолчанию 5)


## Технологический стек
- Go 1.22+
- tview (TUI)
- gRPC Finam Trade API
- Bybit Go SDK
- SQLite (modernc.org/sqlite, без CGO)
- godotenv для чтения `.env`
